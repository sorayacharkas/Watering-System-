# Tank watering system (FSM)

A water-tank controller built from logic gates and flip-flops: a 4-state finite state machine.

| State | |
|---|---|
| S0 | idle, waiting for start |
| S1 | filling until the tank is full |
| S2 | draining until the minimum level |
| P | paused, from any state |

- `watering_system.pdsprj`: circuit (open in Proteus)
- `report-fa.pdf`: state design and circuit (Persian)

Digital Logic course, Sharif University of Technology (2022).
